# myWebs

## 두구두구 중대발표 (`dramatic-reveal/`)

URL 파라미터로 받은 문구를 쓸데없이 웅장한 연출(자막, 북소리, 두구두구) 뒤에 폭죽과 함께 공개하는 페이지입니다.

- `?text=공개할내용` — 공개할 문구 (필수)
- `&from=보낸사람` — 보낸 사람 (선택)

예: `dramatic-reveal/index.html?text=오늘 점심은 김치찌개&from=총무팀`

파라미터 없이 열면 문구를 입력해 링크를 만드는 화면이 나옵니다. 빌드 없이 HTML 파일 하나로 동작하며, 소리는 Web Audio API로 브라우저에서 합성합니다.
